Framework utilizado: Bootstrap

Como ainda estamos aprendendo sobre WebDev a gente precisou olhar alguns tutoriais para tirar dúvidas e saber como aplicar certas ideias que tivemos. Em vários tutorias que olhamos, o framework utilizado foi o Bootstrap, que parecia uma opção bem mais prática e intuitiva de se utilizar que o TailWind, o primeiro framework que escolhemos.

Principais aplicações e porque exatamente decidimos continuar com o Bootstrap:

    Facilidade com componentes: Fazer um "Modal" (aquela janelinha de formulário que pula na tela) do zero usando só JS e CSS puro é bem difícil no começo. O Bootstrap já me deu isso praticamente pronto, além de botões e campos de formulário bem mais bonitos que os padrões do navegador.

    Ajuda com a responsividade: Fazer o site se adaptar para a tela do celular é um baita desafio. As classes prontas do Bootstrap me ajudaram a deixar a estrutura principal organizadinha sem eu ter que escrever dezenas de linhas de código CSS.
